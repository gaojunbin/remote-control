### Install the Android app

1. Download `Remote-Control-<version>.apk` below on the phone, open it, and allow your browser or file
   manager to install apps when Android asks (Settings → Apps → Special app access → Install unknown
   apps).
2. Sign in with your gateway's address (`https://…`), your username and your password.

Android 10 or later. The `.sha256` file beside it holds its checksum
(`sha256sum -c Remote-Control-<version>.apk.sha256`). An APK signed with another key than the one
installed cannot replace it: uninstall the old app first if Android refuses the update.
